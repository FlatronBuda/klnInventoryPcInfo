# KLN PC Info

Приложение для Windows, которое показывает сведения о материнской плате и MAC-адреса физических сетевых адаптеров, формирует QR-коды и печатает идентификационные бирки оборудования.

## Возможности

- Получение производителя и серийного номера материнской платы.
- Поиск физических сетевых адаптеров с фильтрацией беспроводных и виртуальных устройств по имени.
- Отображение сведений в карточках с QR-кодами.
- Копирование значения карточки в буфер обмена.
- Печать бирки размером 60 × 30 мм для выбранного MAC-адреса.
- Последовательная печать бирок для всех найденных MAC-адресов.
- Сохранение названия компании и позиции печати между запусками.

## Требования и установка

Для получения данных оборудования необходима Windows с доступной командой `powershell` и поддержкой `Get-CimInstance`. Для запуска исходного кода нужен Python 3 с установленными зависимостями. Для печати требуется настроенный принтер и его драйвер.

Зависимости в `requirements.txt`:

```txt
PyQt5>=5.15,<6
qrcode[pil]
```

`PyQt5` отвечает за интерфейс и печать. `qrcode[pil]` устанавливает средства генерации QR-кодов вместе с Pillow для работы с изображениями. Модули `sys`, `os`, `json`, `subprocess` и `io` входят в стандартную библиотеку Python.

В командной строке Windows перейдите в папку проекта и выполните:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Сохраните Python-код программы в файл, например `main.py`, и запустите:

```bat
.venv\Scripts\python.exe main.py
```

Здесь `main.py` — пример имени: если исходный файл называется иначе, укажите его имя. Приложение должно иметь возможность записывать `config.json` в свою папку.

Необязательный файл `favicon.ico` задаёт значок окна. При запуске исходного кода он ищется относительно текущей рабочей папки, поэтому запускать программу удобно из папки проекта.

## Как пользоваться

1. Запустите приложение и дождитесь получения сведений об оборудовании.
2. Проверьте производителя, серийный номер материнской платы и найденные MAC-адреса.
3. При необходимости нажмите «Копировать» на нужной карточке.
4. Введите название компании, которое должно присутствовать на бирке.
5. Выберите «Позиция в строке»: 1, 2 или 3.
6. Нажмите «Сохранить», чтобы сохранить настройки.
7. Для отдельного адаптера нажмите «Печать бирки» на его карточке и выберите принтер в диалоге печати.
8. Для последовательной печати всех найденных MAC-адресов нажмите «Печать всех бирок».

При печати программа также пытается сохранить изменённые настройки. Ошибка сохранения выводится в отдельном сообщении, но сама по себе не останавливает печать.

## Логика работы

### 1. Загрузка настроек

При запуске программа читает `config.json`. При отсутствии файла или ошибке его чтения используются пустое название компании и позиция 1.

При запуске Python-файла конфигурация хранится рядом с исходным файлом. При запуске упакованного приложения — рядом с исполняемым файлом.

Пример конфигурации:

```json
{
    "company_name": "Название компании",
    "label_position": 1
}
```

### 2. Получение сведений об оборудовании

Программа запускает PowerShell без отдельного консольного окна и запрашивает:

| Источник | Данные |
| --- | --- |
| `Win32_BaseBoard.Manufacturer` | Производитель материнской платы |
| `Win32_BaseBoard.SerialNumber` | Серийный номер материнской платы |
| `Win32_NetworkAdapter` | Сведения о сетевых адаптерах и MAC-адресах |

Для производителя и серийного номера отбрасываются служебные значения вроде `unknown`, `default string`, `to be filled by o.e.m.`, `n/a` и `none`. Если полезное значение получить не удалось, карточка показывает «Не определён».

Данные запрашиваются при создании окна. Периодического обновления оборудования в текущем коде нет: для повторного чтения нужно перезапустить программу.

### 3. Отбор сетевых адаптеров

В список попадают адаптеры, для которых:

- присутствует непустой MAC-адрес;
- `PhysicalAdapter` равен `true`;
- `NetConnectionID` не равен `null`;
- имя не содержит `Wi-Fi`, `Wireless`, `WLAN`, `Bluetooth`, `Virtual`, `VPN`, `Hyper-V`, `VMware` или `VirtualBox`.

MAC-адреса приводятся к верхнему регистру, повторяющиеся адреса удаляются. Название подключения используется как заголовок карточки; при его отсутствии используется название адаптера, затем `Ethernet`.

Фильтрация по имени зависит от названий, возвращаемых системой. Проверки наличия кабеля, доступа к сети или текущего состояния подключения в коде нет. Если адаптеры не найдены, приложение показывает «MAC-адреса не найдены».

### 4. Создание карточек и QR-кодов

Для производителя, серийного номера и каждого найденного MAC-адреса создаётся отдельная карточка. Карточки размещаются в три столбца внутри прокручиваемой области.

QR-код содержит текстовое значение соответствующей карточки. Для неизвестного производителя или серийного номера в QR-код также попадает текст «Не определён». QR-коды создаются в памяти; автоматического сохранения изображений на диск нет.

Кнопка «Копировать» копирует текстовое значение и на одну секунду меняет надпись на «Скопировано». Кнопка печати есть только у карточек MAC-адресов.

### 5. Содержимое и размещение бирки

На бирке печатаются QR-код с **одним MAC-адресом**, этот MAC-адрес текстом, а также название компании, производитель и серийный номер материнской платы, если они доступны. Сведения о компании и материнской плате не включаются в QR-код бирки.

| Параметр | Значение |
| --- | --- |
| Формат страницы по умолчанию | A4 |
| Размер бирки | 60 × 30 мм |
| Верхний отступ | 5 мм |
| Горизонтальный промежуток между позициями | 2 мм |
| Левый отступ позиции 1 | 5 мм |
| Левый отступ позиции 2 | 67 мм |
| Левый отступ позиции 3 | 129 мм |
| Размер QR-кода на бирке | 25 × 25 мм |

Позиция определяет только столбец в верхней строке листа. Выбор строки и автоматический переход к следующей позиции не реализованы. Размеры в миллиметрах пересчитываются в координаты принтера с учётом его разрешения.

В заголовке диалога указан Canon LBP6000B, но код не выбирает эту модель автоматически: принтер выбирается пользователем в системном диалоге.

### 6. Печать всех бирок

Программа перебирает найденные адаптеры и отдельно вызывает печать для каждого MAC-адреса. Для каждой бирки открывается свой диалог и создаётся отдельное задание печати. Во всех заданиях используется одна выбранная позиция.

**Кнопка «Печать всех бирок» не размещает несколько бирок на одном листе автоматически.** Отмена очередного диалога или невозможность начать печать прерывает дальнейший перебор.

## Особенности текущей версии

- Сбор аппаратных сведений ориентирован на Windows и PowerShell.
- При ошибке PowerShell возвращаются пустые данные; подробная причина в интерфейсе не показывается.
- Программа запрашивает серийный номер материнской платы, который может отличаться от серийного номера компьютера на корпусе.
- Длинные значения на печатной бирке могут обрезаться: текст рисуется в одну строку, автоматический перенос не реализован.
- На диске сохраняются настройки; отдельной базы оборудования и истории печати нет.
- В исходном коде нет отправки собранных сведений на внешний сервер.
